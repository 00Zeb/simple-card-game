TDD myths

“TDD is writing the tests first”

“You don’t write ‘the tests’ first. You write a test first.”

Tim Ottinger

“TDD is not really about writing tests before code. It’s about using tests in short-lived RGR cycles as a tool to design code.”

Andrea Laforgia

“The tests that drive our design often correspond to good regression tests, but certainly not always.”

Jason Gorman

All three come back later. Ottinger returns on the tiny-steps slide (GLM wrote all its tests up front). Laforgia returns on the charade slide (by his definition the agents did test-first, not TDD). Gorman returns on tiny steps and in mutation testing; he mutation-tests new code routinely.
