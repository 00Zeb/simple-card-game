Test-first becomes spec-first.

From Beck’s TDD by Example to Adzic’s Specification by Example.

Write the expectations as BDD-style examples before any code.

Let the agent decide everything below them.

Have something the agent didn’t write check the result.

42:00–44:00. The bookend: the old talk was called “TDD: By Example”. Three lines, three callbacks: the examples (Adzic), everything below them (move up a loop: the agent keeps its own test list and cycles), and something the agent didn’t write (Laforgia’s different fox; in the experiment, the acceptance suite the agents never saw). If someone asks about BDD tools: the step definitions decide what actually gets checked, so they belong to the human or a second reviewer, not to the agent writing the code.
