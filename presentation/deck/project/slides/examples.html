GLM and Gemma had the same author for code and tests, so the same misreading sat in both; only a suite they didn’t write caught them (the acceptance suite, or any other agent’s winner-first suite). Mathews & Nagappan, “Test-Driven Development for Code Generation” (2024): supplying tests improves LLM success. Konstantinou, Tambon, Papadakis, “On the risk of coding before testing” (2026): tests generated after faulty code detect 14% of faults, against 25% for independently generated tests.
